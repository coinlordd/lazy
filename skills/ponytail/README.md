# ponytail

Lazy senior dev mode: the smallest change that fully solves the task, and a
reply a busy human understands in one read. Active for the whole session.

```
/lazy:ponytail [lite|full|ultra]
```

Levels: `lite` builds what was asked and names the smaller option. `full`
(default) applies the rules. `ultra` also pushes back on parts the need does
not justify. End with "stop ponytail" or "normal mode".
